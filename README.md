# Sheet Music Maker

Turns the vocal melody of an MP3 into a simple sheet-music PDF (single melody line, with a line under each staff for lyrics). Everything runs in the browser; no audio is uploaded.

## Files
- `index.html` – the whole app
- `sheet-music-maker-icon.png` – 180x180 Home Screen icon (you make this one; the `apple-touch-icon` link is already in `index.html`)

## Use
1. Choose one or more MP3s, pick the song.
2. Adjust settings if needed (voice type, tempo, time signature, start/end seconds to skip an intro).
3. Tap **Create sheet music**, then **Save PDF** or **Share PDF**.
4. Add lyrics later: paste them in the Lyrics box (one line per staff) and tap the button again. No re-analysis needed.

If the notes look twice as fast or slow as the song, tap the 1/2x or 2x tempo button.

## Publish (GitHub Pages)
Commit `index.html` and the icon to the repo, wait 1-2 minutes, reload.
